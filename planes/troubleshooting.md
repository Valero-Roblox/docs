# Troubleshooting:

**Is your game a group game?**
If so, then make sure that the Configuration folders are set correctly. The folders can be found in “Put me in ReplicatedStorage (folder) > Configuration” and in each of the plane models, for example “787 > Configuration”. 
If you have trouble locating the folders, open a customer service ticket for more help.

**If you are having trouble setting up your plane, watch this video:**
https://www.youtube.com/watch?v=n5x0brk8PXM

If you are still having issues, you can read the following:

**Claiming Order:**
If you experience any bugs/issues, contact customer service in the discord above.

**Using the plane:**
If your plane is not working as intended, then make sure you are following these guidelines:

**Make sure HttpService is enabled at the game**
- If you are using a group game, make sure the GroupID is set in BOTH of the configuration folder
- The game you are owning is owned by the user you put in the shoppy text box.
- Make sure you are not testing in roblox studio, the plane will only work in game.
- Using the spawner

- Make sure all of the above instructions have been done

- If you are using a group game, make sure the Configuration folder in the spawner is set, as well as the Configuration folder in the planes too. All folders must be set

- Make sure the model names of the plane are set correctly and correspond with the plane, for example:
  Edition-x should be named: “edx”
  The 787 should be named: “787”
  The 757 should be named: “757”
  The 737 should be named: “737”

- Make sure that the PrimaryPart of the plane model (a value in properties) is set to the “Main” part in the animations folder in the plane.
